# Explicit IMF expression discovery

The [completed pilot report](report/symbolic_imf_pilot_complete.html) is in
`report/`. It covers explicit function discovery for individual VMD intrinsic
mode functions, including random, pretrained, and adapted generator arms.
It is distinct from the shared neural waveform-representation pilot.

The standalone HTML embeds its figures, audio, and linked records. The original
run, checkpoint, full job records, and incremental report remain under
`runs/parametric_symbolic_imf_pilot`.

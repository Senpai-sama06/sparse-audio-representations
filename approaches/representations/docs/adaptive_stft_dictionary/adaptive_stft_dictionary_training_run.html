Adaptive STFT dictionary: training run

Run ID: adaptive_stft_dictionary_librispeech_20261107. Training completed on 7 November 2026.

Purpose

This experiment examines a model that generates spectral atoms for each audio input. It tests reconstruction with a fixed atom count.

Scope

Training used one-second LibriSpeech excerpts. The model has 32 complex atoms and dense complex coefficients.

The test group contains 64 test-clean utterances from 40 speakers. Each utterance has an excerpt case and a complete-recording case.

The report contains all 128 selected cases. No selected case failed or was excluded.

This experiment does not test residual vector quantization, intrinsic mode functions, or a minimum-size dictionary objective.

A compressed codec bitstream is not available. The measured files contain an uncompressed float32 representation.

Method

STFT means short-time Fourier transform. It gives the real and imaginary frequency values for successive time windows.

Input audio
  -> shared gain normalization
  -> complex STFT
  -> audio encoder
  -> input-specific atom generator
  -> initial coefficient calculation
  -> four joint dictionary and coefficient update stages
  -> dictionary product and endpoint correction
  -> inverse STFT and gain restoration
  -> reconstructed audio

The encoder and atom generator share network weights across recordings. Each recording receives different atom values.

One dictionary serves all frames in an input. The coefficients change over time.

The update stages change both atoms and coefficients. Their correction networks share weights across stages.

All output audio passes through the dictionary product. The model has no waveform bypass and no vocoder.

The loss combines complex STFT error, waveform L1 error, and multiresolution spectral error. Earlier stages also receive reconstruction supervision.

Training procedure

FLAC means Free Lossless Audio Codec.

  1. Resolve the cached KaggleHub dataset pypiahmad/librispeech-asr-corpus/versions/1.
  2. Check FLAC headers and official partition names.
  3. Check that training, validation, and test speakers do not overlap.
  4. Save the file index and fixed validation offsets.
  5. Evaluate the initial model on 64 fixed dev-clean excerpts.
  6. Train for 20,000 updates.
  7. Evaluate validation excerpts every 500 updates.
  8. Save the checkpoint with the lowest final-stage composite validation loss.
  9. Evaluate the saved best checkpoint on the fixed test group.

The index contained 104,014 train-clean-360 files, 2,703 dev-clean files, and 2,620 test-clean files.

No source file was excluded for insufficient length. Training selected speakers uniformly before it selected an utterance and crop offset.

The batch size was eight. The run used 160,000 sampled one-second excerpts, equivalent to 44.44 hours of sampled audio.

This sampling schedule does not equal one pass through all 360 hours.

Evidence

The composite validation loss decreased from 3.6439 to 1.8937. This is a 48.0% decrease.

The final validation waveform normalized mean squared error was 0.1883 across 64 fixed excerpts.

These observations support improved reconstruction. They do not identify which model component caused the improvement.

Limits and unresolved problems

  • The test group is a selected subset. It is not the complete test-clean dataset.
  • Complete-recording inference extends the one-second training context.
  • The excerpt and complete-recording modes evaluate different audio durations.
  • The scores alone do not establish listening quality or intelligibility.
  • A stronger coefficient solve can improve reconstruction on the small validation diagnostic group.
  • A fixed-dictionary training comparison has not been completed.
  • The available evidence does not isolate the benefit of input-specific atoms.
  • The raw payload results do not establish compression.

1. Purpose and technical terms

The model learns how to make spectral atoms from an audio recording. The atom values change with each recording.

One dictionary serves all valid STFT frames in that recording. The coefficients change between frames.

The first experiment examines reconstruction quality. The number of atoms stays constant during each run.

Later experiments can examine sparsity, quantization, description length, RVQ, and IMF decomposition.

1.1 Shared parameters and input-specific values

  • The encoder, atom generator, and correction networks have shared network weights.
  • Training changes the shared network weights.
  • Each recording has its own dictionary and coefficients.
  • During evaluation, the shared network weights stay constant.
  • The update stages still change the dictionary and coefficients for each recording.

2. Model diagram and settings

Figure 1 shows the signal flow. Gray blocks contain networks with shared weights. White blocks perform specified signal operations.

The dashed boundary contains four update stages. The stages use the same correction networks.

2.1 Main equations

D_i^0 = G_theta(E_phi(S_i))
S_hat_i = Pi(D_i^L A_i^L)
x_hat_i = gain_i * inverse_STFT(S_hat_i)
  • E is the encoder.
  • G is the atom generator.
  • Pi removes the imaginary values at the DC and Nyquist output bins.
  • L is the number of update stages.
  • The subscript i identifies a recording.

2.3 Tensor dimensions

B is the batch size. F is the number of frequency bins. T is the number of time frames.

K is the number of atoms. The dimension 2 identifies the real and imaginary channels.

  • Input STFT S: B × 2 × F × T.
  • Encoder features H: B × T × 128.
  • Dictionary D: B × 2 × F × K.
  • Coefficients A: B × 2 × K × T.

3. Model blocks

3.1 Block 1: prepare the waveform and calculate the STFT

This block controls the signal scale and keeps the phase information.

  1. Read the waveform, sample rate, and valid sample count.
  2. Calculate one RMS gain for the recording.
  3. Apply a specified lower limit to the gain for silence.
  4. Divide the waveform by the gain.
  5. Keep the gain for the inverse operation.
  6. Calculate the complex STFT.
  7. Make a mask that identifies valid frames.

Both complex channels use the same gain. Independent channel normalization changes their relationship.

The frame mask excludes padded data from attention and loss calculations.

Check: the waveform, gain, sample count, frame mask, and complex channels. Check the STFT inverse before training.

3.2 Block 2: extract features with the audio encoder

The encoder supplies information about frequency content and changes over time.

The proposed encoder has a convolutional stem and residual blocks. Its successive feature widths are 32, 64, and 128 channels.

The encoder reduces the frequency dimension slowly. It keeps the time grid.

A frequency coordinate gives the position of each input bin. The encoder output contains 128 values per time frame.

Frequency reduction inside the encoder does not remove frequency bins from the reconstruction target.

Check: feature values, gradient values, frequency sensitivity, and frame masks. Examine weak high-frequency signals after each reduction step.

3.3 Block 3: generate atoms for the input

The atom generator makes the initial dictionary for the current recording.

  1. Use K learned query vectors.
  2. Apply cross-attention between the queries and encoder features.
  3. Use four attention heads.
  4. Apply a residual feed-forward block.
  5. Project each query output to 2F values.
  6. Reshape these values into the real and imaginary parts of an atom.
  7. Normalize each atom over its complex frequency values.

The queries provide starting vectors. The encoder features make their outputs different for each recording.

The model learns sampled spectral shapes. It does not select atoms from a fixed list of complete mathematical functions.

One dictionary serves the complete excerpt. A dictionary that changes within an excerpt requires a separate experiment.

The proposed encoder uses the complete excerpt. Causal operation requires a different input policy.

Check: atom magnitude, atom phase, query attention, and repeated atoms. Compare dictionaries from different recordings.

3.4 Block 4: calculate initial coefficients

The coefficients control atom strength and phase rotation in each frame.

Use the projection DHS as an initial estimate. Apply a scale correction based on the dictionary operator norm.

The superscript H means conjugate transpose. The projection is not an inverse for a general nonorthogonal dictionary.

A regularized least-squares solve is an alternative initialization method.

Real(D A) = D_R A_R - D_I A_I
Imaginary(D A) = D_R A_I + D_I A_R

The first experiment permits dense coefficients. A threshold can describe effective activity, but it does not establish learned sparsity.

Check: initial error, coefficient scale, activity over time, and phase rotation.

3.5 Block 5: update coefficients and atoms

Each stage uses the reconstruction residual to change the coefficients and atoms.

The data steps follow the fidelity loss. Learned correction networks supply rules from the training data.

A_temp = A - eta_A * gradient_A L_complex(Pi(D A), S)
A_new = A_temp + bounded_correction_A(A_temp, H)
D_temp = D - eta_D * gradient_D L_complex(Pi(D A_new), S)
D_new = normalize[D_temp + bounded_correction_D(D_temp, H)]

The coefficient correction network operates over time. The atom correction network operates over frequency.

Both networks receive encoder features. The step sizes are positive and have specified upper limits.

Start the residual correction outputs at zero. This starts the model near the specified data-update operations.

Use the same correction-network weights in all four stages.

The alternating update structure follows ideas from DCDicL [1] and the seismic method [8].

Atom normalization

Normalization must preserve the represented signal.

  1. Calculate the norm n of each updated atom.
  2. Divide the atom by n.
  3. Multiply its coefficient row by n.
  4. Use a specified procedure for atoms with a near-zero norm.

This scale change preserves the product D A.

Gradient calculation

Include the endpoint projection Pi in the loss calculation. Obtain gradients through the actual real and imaginary operations.

A complex update formula can give an incorrect gradient if it excludes the projection.

Check: error before and after each substep, update size, gradient norm, and step-size limits.

A learned correction can increase the error. Measure the result at every stage.

3.6 Block 6: calculate the output STFT

This block makes the complete output spectrum from the final atoms and coefficients.

  1. Multiply D by A.
  2. Set the imaginary DC value to zero.
  3. Set the imaginary Nyquist value to zero.

The endpoint rule applies to the proposed even FFT length.

Complex coefficients can make the product endpoints imaginary. Real atom endpoints alone do not prevent this.

All output audio must pass through the dictionary product. The model has no encoder-to-waveform bypass.

Check: real and imaginary errors, frequency-band errors, and values removed by the endpoint projection.

Also compare the predicted spectrum with STFT(inverse_STFT(predicted spectrum)). This difference measures STFT consistency.

Correct endpoint values do not guarantee STFT consistency across overlapping frames.

3.7 Block 7: calculate output audio and the loss

The inverse operation must use the same window, hop, and centering settings as the analysis operation.

  1. Calculate the inverse STFT.
  2. Set the output length to the original sample count.
  3. Restore the stored input gain.
  4. Save the output without automatic alignment or gain correction.

The proposed training loss has three terms.

L_total = lambda_c * L_complex
        + lambda_w * L_waveform
        + lambda_m * L_multiresolution

L_complex = ||Pi(D A) - S||^2 / (||S||^2 + epsilon)
Loss termPurpose
Complex STFT errorDecrease errors in the real and imaginary channels.
Waveform L1 errorDecrease the waveform error after the inverse STFT. Use the normalized waveform for this term.
Multiresolution spectral errorCompare log magnitude and spectral convergence at several window sizes.

Apply valid-region masks. Specify separate handling for silence.

Start with equal weights for the normalized loss terms. Record each term separately.

Give the final stage a supervision weight of 1. Divide a total weight of 0.5 among the earlier stages.

These weights are proposed experiment settings. Separate comparisons must examine their effects.

Backpropagation passes through the complete sequence of updates. It changes the shared network weights during training.

Check: output timing, gain, boundary error, clipping, and gradients from each loss term.

Use complete utterances for PESQ and STOI. These scores do not give reliable evidence for isolated 40 ms signals.

4. Signal checks

The following checks specify data to collect during implementation. They do not contain measured model results.

4.1 Check the analysis and inverse operations

  1. Save the input waveform, input gain, STFT, and masks.
  2. Calculate the inverse of the unchanged STFT.
  3. Measure the error, output length, time delay, and amplitude ratio.
  4. Measure boundary error separately from interior error.

If this check fails, examine the window, padding, centering, sample rate, and inverse length.

4.2 Check the encoder information

  1. Save feature norms by time and frequency.
  2. Save attention masks and gradient maps.
  3. Supply tones, harmonic mixtures, chirps, and time-shifted signals.
  4. Compare changes in features, attention, and atoms.

If the encoder misses signal changes, examine frequency reduction, normalization, coordinates, and masks.

4.3 Check changes in the dictionary

  1. Use a fixed set of recordings for inspection.
  2. Save the initial and final dictionaries.
  3. Plot atom magnitude and phase.
  4. Repeat inference for the same input.
  5. Compare the result with dictionaries from other inputs.

Match atom order before comparison. Correct equivalent complex phase rotations before comparison.

If the dictionary stays constant, examine the input connections, attention, and generator gradients.

4.4 Check atom utility and repeated atoms

  1. Save the complex Gram matrix DHD.
  2. Save atom norms, coefficient energy, and dictionary singular values.
  3. Remove one atom.
  4. Measure the error before a new coefficient solve.
  5. Solve the remaining coefficients again.
  6. Measure the error after that solve.

This procedure separates immediate atom use from replacement by other atoms.

Useful atoms can overlap in frequency. Do not require orthogonality without a separate comparison.

4.5 Check coefficient inference

  1. Save initial and final coefficients.
  2. Keep the dictionary constant.
  3. Calculate a strong least-squares or regularized solution.
  4. Compare its error with the learned inference error.

If the numerical solve gives lower error, improve inference before you increase dictionary capacity.

4.6 Check each update stage

  1. Record the loss before the coefficient data step.
  2. Record the loss after the coefficient data step.
  3. Record the loss after its learned correction.
  4. Repeat these measurements for the atom update.
  5. Record the loss after atom normalization.
  6. Record update norms and step sizes.

If the error oscillates, examine the step limits and correction sizes. Check the coefficient scale change during normalization.

4.7 Check spectrum and phase errors

  1. Save reference and predicted magnitude spectra.
  2. Save real and imaginary residuals.
  3. Measure errors by frequency band.
  4. Measure the endpoint projection change.
  5. Measure STFT consistency error.
  6. Measure phase error only in bins with sufficient reference energy.

A correct magnitude plot does not establish correct audio reconstruction.

4.8 Check the output waveform

  1. Save the original waveform and each stage output.
  2. Preserve the original amplitude in listening files.
  3. Measure waveform NMSE, SI-SDR, spectral error, and boundary error.
  4. Listen for clicks, missing speech components, and gain changes.

If clicks occur, examine the inverse framing and normalization. Do not correct output timing silently before the primary measurements.

4.9 Check training and generalization

  1. Record training and validation losses separately.
  2. Record each loss term and each stage result.
  3. Keep the initial, best, and last checkpoints.
  4. Record learning rates and gradients for each module.
  5. Use validation speakers that do not occur in the training set.

If only training improves, examine capacity, data selection, and leakage. Keep the initial validation result as a baseline.

4.10 Check whether adaptation causes the improvement

  1. Replace the input dictionary with a fixed dictionary.
  2. Solve its coefficients with the same inference budget.
  3. Replace the dictionary with another recording's dictionary.
  4. Solve its coefficients with the same inference budget.
  5. Compare these errors with the original result.
  6. Compare generation alone with generation followed by updates.

A dictionary and its coefficients must remain a matched pair. An unmatched pair can fail without proving useful adaptation.

4.11 Interpretation limits

Atom order can change without changing the represented signal.

A complex phase factor can move from an atom into its coefficients. The product D A can stay constant.

Use atom matching and controlled replacements. Different atom plots alone do not establish useful adaptation.

4.12 Required inspection records

  • Input identity, source offset, sample count, and analysis settings.
  • Stored gain and valid-region masks.
  • Dictionary and coefficient values at each stage.
  • Stage errors, band errors, and solver information.
  • Waveform plots and audio files.
  • Checkpoint identity and experiment settings.

Keep full evaluation tables separate from selected examples. Include difficult examples and failed runs.

A future results report must contain its own plots and audio data. This permits sharing one HTML file.

5. Feature preparation

Feature preparation defines the information that the model receives. The model learns the atom shapes.

ItemInitial choiceAlternative or check
Frequency representationUse real and imaginary STFT values on a linear frequency axis.Magnitude or mel features can supply additional encoder information. Keep the complex reconstruction target.
Amplitude scaleUse one RMS gain per recording.Compare with no normalization. Check silence handling and gain restoration.
Frequency positionSupply a coordinate f / f_Nyquist.Compare an encoder without this coordinate.
Time informationKeep time tokens and valid-frame masks. Use local convolutions and attention.Examine time coordinates separately. Absolute frame positions can encourage position-specific solutions.
Dynamic rangeUse linear complex values as the primary input.Test log magnitude as an additional encoder channel. Specify its scale.
Frequency weightsUse no preferred frequency band in the primary complex loss.Test high-frequency loss weights separately, as suggested by HyperSound [6]. Report errors in every band.
Atom shape restrictionsPermit unrestricted sampled spectral shapes.Test frequency-spread or smoothness penalties separately. Narrow-band restrictions can remove useful harmonic or broadband patterns.
Training data changesUse random waveform crops and separate speaker groups.Test time shifts with controlled signals. Treat pitch shifts and added noise as separate experiments.
Phase informationUse both complex channels. Do not supply separate phase labels.Exclude low-energy bins from phase-error summaries.

Do not apply a real logarithm to signed real or imaginary values.

The model receives no prescribed atom-frequency labels. Frequency centers, bandwidths, and harmonic relationships are measurements after training.

An association with a speech sound does not prove a unique atom meaning.

6. Alternative blocks from the papers

Each subsection gives one separate replacement experiment. The audio adaptations are our proposals.

Codebook entries, feature tokens, and spectral atoms are different technical objects. Their names do not make their methods equivalent.

6.1 DCDicL: replace the update procedure [1]

Source method: alternate dictionary and coefficient data solves with learned priors.

Replacement: use half-quadratic splitting in block 5. Use regularized least-squares subproblems and separate learned priors for D and A.

Question: do these data solves improve stability or reduce the required stages?

A learned correction does not guarantee an exact minimum. See reference 1.

6.2 AdaCode: restrict the atom generator [2]

Source method: combine quantized features from shared codebooks with input-specific weights.

Replacement: learn shared spectral dictionary templates. Predict weights for the current recording. Combine the templates to obtain D.

D_i = sum_m w_i,m * B_m

Question: does this restricted adaptation improve generalization?

This equation is our proposed analogy. It is not the exact AdaCode implementation. See reference 2.

6.3 Masked sparse representation: mask adaptation weights [3]

Source method: mask codebook-combination weights and recover their effect with a learned network.

Replacement: mask selected template weights after the template-mixture method works. Train a network to recover useful missing information.

Question: how much adaptation information can the model remove before reconstruction fails?

This is a later experiment. Quantization and bitrate objectives require additional work. See reference 3.

6.4 Adaptive Token Dictionary: repeat query adaptation [4]

Source method: refine dictionary tokens with input features and use category-based attention.

Replacement: repeat attention between atom queries and encoder features in blocks 2 and 3.

Convert the resulting tokens into explicit spectra.

Question: does repeated attention improve D A reconstruction over one attention step?

The paper uses internal feature tokens. Spectral synthesis atoms are our extension. See reference 4.

6.5 Dynamic segmentation dictionary: exchange information in both directions [5]

Source method: alternate attention between image features and class embeddings.

Replacement: let features update atom tokens. Then let atom tokens update the context for the next stage.

Question: does this exchange improve adaptation?

The segmentation paper uses class labels and a contrastive loss. Our reconstruction task has no equivalent class targets.

Do not transfer that loss without appropriate targets. See reference 5.

6.6 HyperSound: generate atom functions [6]

Source method: a hypernetwork generates a neural function for each audio input.

Replacement: replace the direct projection in block 3. Generate parameters for functions that give complex atom values at frequency coordinates.

Question: does a continuous atom function improve reconstruction or generalization?

This is our extension of HyperSound. Measure function evaluation cost and high-frequency errors. See reference 6.

6.7 Instance-adaptive compression: add per-recording optimization [7]

Source method: adapt a pretrained model to an input instance. Include transmitted model updates in its rate objective.

Replacement: use the generator output as the initial state for optional per-recording optimization.

Question: does additional optimization improve reconstruction at a specified computation budget?

Updating D and A differs from updating shared network weights. Identify these alternatives separately.

Transmission costs belong to a later coding experiment. See reference 7.

6.8 Seismic DCDL: use learned priors or convolutional atoms [8]

Source method: use a dictionary for each seismic slice. Apply alternating data solves and learned coefficient and dictionary priors.

Replacement A: use its update structure in block 5.

Replacement B: replace spectral-column atoms with small time-frequency patches and convolutional coefficients.

Question: do patches represent useful local structures that spectral columns miss?

Run these replacements separately. Frequency translation can change harmonic spacing and its physical meaning.

The seismic method builds on DCDicL. These papers are related precedents. See reference 8.

7. First experiment

7.1 Establish reference results

  1. Verify unchanged STFT inversion.
  2. Evaluate a fixed complex dictionary with a strong coefficient solve.
  3. Evaluate per-recording truncated complex SVD.
  4. Include tones, chirps, mixtures, speech, and silence.

7.2 Train the atom generator

  1. Train the encoder, atom generator, and coefficient inference blocks.
  2. Exclude dictionary-update stages from this first model.
  3. Keep the atom count constant.
  4. Compare the initial and trained checkpoints on unseen speakers.

7.3 Add joint updates

  1. Compare one, two, and four stages.
  2. Compare data updates alone with data updates plus learned corrections.
  3. Keep input context, atom count, and loss settings constant.
  4. Record inference time separately.

7.4 Measure useful adaptation

  1. Perform the dictionary-replacement checks in section 4.10.
  2. Repeat the strongest settings with several random seeds.
  3. Report individual recording errors and the complete evaluation summary.
  4. Keep difficult examples and failures.

7.5 Select checkpoints

Use a fixed composite validation reconstruction score. Record all its terms.

Keep the initial checkpoint. Use a specified training budget or a specified validation-plateau rule.

Fix the checkpoint choice before final testing.

The experiment succeeds if adaptation improves unseen-recording reconstruction under the declared comparison conditions.

A lower training loss alone does not establish this result.

7.6 Interpret the SVD reference

With dense coefficients, D A has rank at most K.

Truncated complex SVD gives the optimal rank-K approximation for unweighted complex-matrix squared error.

It does not optimize the complete waveform and spectral loss in this proposal.

7.7 Interpret short excerpts

The proposed STFT settings give six frames for 640 samples.

With K of at least six, an unrestricted matrix factorization can reproduce that spectrum exactly in principle.

Thus, exact reconstruction of one 40 ms excerpt gives weak evidence for useful learned atoms.

8. Paper references

The following titles and author names retain their source wording. External links require an internet connection.

[1] Deep Convolutional Dictionary Learning for Image Denoising

Hongyi Zheng, Hongwei Yong, Lei Zhang. CVPR, 2021, pages 630-641.

The method learns dictionary and coefficient priors. It adapts a reconstruction dictionary to each image.

Training uses L1 supervision at successive stages. Evaluation uses PSNR and SSIM.

This paper supplies the main alternating-update precedent.

Publication page. Author PDF.

[2] Learning Image-Adaptive Codebooks for Class-Agnostic Image Restoration

Kechun Liu, Yitong Jiang, Inchang Choi, Jinwei Gu. ICCV, 2023.

AdaCode predicts image-specific weights for combinations of codebook representations.

Its stages use reconstruction, perceptual, adversarial, and code-level losses.

This method suggests a restricted adaptation space for our atom generator.

Paper text. Published PDF.

[3] Neural Image Compression Using Masked Sparse Visual Representation

Wei Jiang, Wei Wang, Yue Chen. WACV, 2024.

The method predicts combination weights for fixed pretrained codebooks. It masks some weights and learns how to recover useful information.

Evaluation compares PSNR, SSIM, and LPIPS with bitrate. The bit count includes codebook indices and combination weights.

This method informs a later adaptation-cost experiment.

Paper text. Published PDF.

[4] Transcending the Limit of Local Window: Advanced Super-Resolution Transformer with Adaptive Token Dictionary

Leheng Zhang, Yawei Li, Xingyu Zhou, Xiaorui Zhao, Shuhang Gu. CVPR, 2024.

The method adapts feature tokens to each image. It uses these tokens in attention operations.

Training uses L1 pixel loss. Evaluation uses PSNR and SSIM.

Our proposed extension converts the adapted tokens into explicit spectral atoms.

Paper and supplement. Publication page.

[5] Dynamic Dictionary Learning for Remote Sensing Image Segmentation

Xuechao Zou, Yue Li, Shun Zhang, Kai Li, Shiying Wang, Pin Tao, Junliang Xing, Congyan Lang. ICCV, 2025.

The method adapts class embeddings through alternating cross-attention.

Training uses segmentation losses and a dictionary contrastive loss. Evaluation uses IoU, F1, and accuracy.

The attention mechanism is relevant to our model. Its class-discrimination objective requires different supervision.

Accessible paper version. Published version.

[6] Hypernetworks build Implicit Neural Representations of Sounds

Filip Szatkowski, Karol J. Piczak, Przemysław Spurek, Jacek Tabor, Tomasz Trzciński. ECML PKDD, 2023.

HyperSound generates neural function parameters for each recording.

Training uses waveform L1 and multiresolution mel-STFT losses. Evaluation examines reconstruction and perceptual quality.

This paper supports audio-conditioned parameter generation. Generating separate atom functions is our proposed extension.

Author PDF. Accessible paper version.

[7] Overfitting for Fun and Profit: Instance-Adaptive Data Compression

Ties van Rozendaal, Iris A. M. Huijben, Taco S. Cohen. ICLR, 2021.

The method adapts a pretrained compression model to a video.

Its objective includes reconstruction distortion, latent rate, and model-update rate.

This paper informs a controlled per-recording optimization comparison. Its transmission-cost objective belongs to a later coding study.

Paper and algorithms. Conference record.

[8] Three-dimensional seismic denoising based on deep convolutional dictionary learning

Yuntong Li, Lina Liu. Results in Applied Mathematics, volume 24, article 100516, 2024.

DOI: 10.1016/j.rinam.2024.100516.

The supplied paper has six pages. Figure 1 and equations 2-5 describe the adaptive dictionary procedure.

The method learns a dictionary for each seismic slice. It uses alternating data solves and learned priors.

Training uses grayscale natural images. Evaluation examines seismic signal-to-noise ratio, structure preservation, and computation time.

The paper denotes the outer loss by L. It does not give a complete loss specification or training schedule.

Do not assume these details from DCDicL.

Publisher page.
